Powerful, simple commands.

Manage your feeds directly from Discord with slash commands.

/trackAdd a creator or source to track.
/untrackRemove a tracked source.
/listView configured feeds.
/testTest a notification configuration.
/statsView feed totals and alerts sent.
/statusCheck the notifier status.
/pingCheck bot response latency.
/helpExplore available commands.

Frequently asked questions.

Some quick answers about Notifier.

How do I add Notifier to my server?

Use the Add to Discord button above. Configure your bot's invite URL in the website settings first.

How do I track a creator?

Use the /track slash command in your Discord server and follow the options provided by your bot.

Does the website run my bot?

No. GitHub Pages hosts this static website. Your Discord bot must run separately on your bot hosting service.

Are all platforms always available?

Availability depends on your bot's current integrations, API credentials and configuration.

Where can I get help?

Join the support server using the Support button after setting its invite URL in the configuration.
